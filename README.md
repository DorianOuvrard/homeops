# HomeOps

Diagnostiquer, réparer et maintenir les appareils d'un logement, simplement.

Projet développé dans le cadre du hackathon **Shift 2026** (Le Palace, Nantes).

## Concept

- Identifier un appareil (photo, plaque signalétique, scan réseau/RF)
- Diagnostiquer une panne à partir d'un symptôme ou code erreur
- Guider la réparation pas à pas avec sourcing des pièces
- Proposer un calendrier de maintenance préventive
